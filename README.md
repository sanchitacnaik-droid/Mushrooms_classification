# 🍄 AI-Based Mushroom Classification System

## 📌 Project Description

The AI-Based Mushroom Classification System is a Machine Learning project that predicts whether a mushroom is **Edible** or **Poisonous** based on its physical characteristics. The project includes data cleaning, preprocessing, visualization, model training, and deployment using Streamlit.

---

## 📂 Dataset Information

- **Dataset Name:** Mushroom Classification Dataset
- **Total Records:** 8124
- **Total Features:** 23
- **Target Column:** class

Target Values:
- **e** → Edible
- **p** → Poisonous

---

## 🎯 Project Objectives

- Perform data cleaning
- Handle missing values
- Encode categorical features
- Train a Machine Learning model
- Predict mushroom class
- Display dataset information using Streamlit
- Build an interactive dashboard
